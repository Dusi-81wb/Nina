# Scripts Directory

This directory contains automation, benchmarking, and helper scripts for the Nina system.

## Planned Scripts

- `benchmark_asr.py`: Run Word Error Rate (WER) benchmarks on sample audio recordings.
- `benchmark_emotion.py`: Run precision/recall/F1 evaluations on test datasets.
- `download_models.py`: Pre-download and cache selected Hugging Face and Whisper models locally.
- `run_cli.py`: Interactive command-line interface for live microphone testing.
