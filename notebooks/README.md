# Research & Exploratory Notebooks

This directory contains Jupyter notebooks used for experimental analysis, dataset exploratory data analysis (EDA), and prototype evaluations.

## Notebook Structure

- `01_asr_exploration.ipynb`: Evaluation of local ASR model output quality across audio variations.
- `02_emotion_eda.ipynb`: Exploratory data analysis on emotion text datasets (e.g. GoEmotions, CARER).
- `03_intensity_heuristics.ipynb`: Analysis of confidence vs linguistic intensifiers for intensity calibration.
